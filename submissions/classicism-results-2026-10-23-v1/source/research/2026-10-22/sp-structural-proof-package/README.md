# Strong Possibility: structural proof package

22 October 2026. Ordinary mathematical research in the fixed Classicist framework. These are separately saved research notes, not changes to the principle database. The arguments received independent AI-agent mathematical audits; none is claimed to have been checked by a named human or formalized. New deductions have direct source **misc**. No claim of literature novelty is made.

**Full pure Strong Possibility remains unresolved.** The explicit positive-fragment models below actually fail one admitted instance, D StrongActuality. This package supplies structural reductions, finite-model classifications, and substantial consistent fragments, not a model or refutation of full SP.

## Framework

C has the bundle's relational type grammar. Max is fixed **pure** Maximalism relative to C. SP is the fixed schema D P for closed pure P with **Max+P consistent**. Its side condition is not mere C-consistency. Here H p = exists q(q and box(diamond q -> p)), and D is H's dual. Optional assumptions are never silently added to C or necessitated.

## Further consequences and boundaries

- Pure SP is incompatible with signature Maximalism for any admitted signature containing a relational constant. Pure and signature schemata must remain distinct. See [profile root, §§9–11, 14, 16](profile-root-construction-20261022.md).
- Finite pointed-completion spaces give exact finite Boolean interval ranks. This was also proved independently in the parallel parent lane; no priority claim is made. See [universal core, §11](reflection-universal-core-20261022.md).
- SP rules out every strong world at every relational type, while weak atoms and Actuality must be distinguished. A necessary standard finite bound on propositions implies D StrongActuality. Finite base domains with BF collapse D on pure formulas with only individual free variables. See [universal core, §§9–12](reflection-universal-core-20261022.md).
- An explicitly specified infinitary enrichment naming the exact standard numerals conflicts with the **old finitary Max schema**. This is not a contradiction in finitary SP or in Max recalculated for a different logic. See [infinitary resources](infinitary-standard-numerals-20261022.md).
