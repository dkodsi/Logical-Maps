## 1. Verdict and exact scope

**PASS, with the presentation qualifications retained:** the principal degree claims are sound. In particular:

1. The closed pure C identity word problem is many-one complete c.e.
2. Every consistent theory whose consequences include Max_C and whose axioms or theorems are c.e. in 0′ has a many-one complete Σ⁰₂ set of closed pure theorems. The reduction is an ordinary computable reduction, not merely one computable in 0′.
3. Every complete actual pure theory extending Max_C computes a binary DNR function relative to 0′. Conversely every oracle computing such a function computes some complete Max_C theory and a countable BBK model equipped with uniform term interpretation and truth.
4. The analogous positive-theory problem with a quantified Frege Axiom of Infinity has precisely PA-level oracle capacity. Every consistent c.e. strengthening of C plus that Infinity axiom has many-one complete c.e. pure theoremhood.
5. The stated Medvedev equivalences and strict comparison are valid for the specified adequately coded models. They do not give exact presentation-degree spectra of fixed isomorphism types.
6. The Stone-space claims follow: the Max locus is closed nowhere dense in S(C), is abstractly a Cantor space, and has a dense set of completions low relative to 0′. The positive finite Gallin package is clopen, and with strong Infinity its completion space is also abstractly a Cantor space.

I found no fatal gap in the self-reference argument or in the required extension of arithmetic induction. The audit below supplies omitted details and a genuinely useful strengthening concerning Actuality (§9). The base non-r.e. assertion remains an already published observation in the accessible Bacon–Dorr draft; this report claims no priority for any refinement.

**Not included in this verdict:** the separate finite-support choice-separation construction, a representation theorem for every model by the auxiliary Gallin subclass, or a degree-preserving conversion into an arbitrary category/action reduct. Those are different questions.

## 3. Arithmetic coding: the exact requirements and why they hold

Fix σ=e for Max_C, ν=(et)t, and the bundle's definitions of N, 0, Suc, Sum, Prod, I*=successor injectivity with zero not a successor, and I=◇I*.

### 3.1 Expanded induction is available

One must not merely say that ordinary PA has been interpreted and then assume induction for a newly added oracle predicate. That additional induction is required for an uncomplicated proof of deterministic oracle computation. Here it is available directly.

For any finite original-language formula ψ(n,ā), including formulas containing □, higher-order quantifiers, or parameters, form the admitted property

    W := λn. (Nn ∧ ψ(n,ā)).

Assume ψ(0,ā) and ∀n∈N (ψ(n,ā)→ψ(Suc n,ā)). C proves N0 and ∀n(Nn→N(Suc n)). Hence W0 and ∀n(Wn→W(Suc n)). The defining universal quantifier of N, instantiated with W, yields ∀n∈N ψ(n,ā). This is the full first-order induction schema after replacing a predicate O by any fixed original-language definition J. It is not an application of Logical Equivalence to an equivalence proved under optional hypotheses.

### 3.2 Why Max_C supplies the arithmetic premise

I* is true in the ordinary full extensional hierarchy on an infinite individual domain. Thus I* is C-consistent. Max_C, in its recorded equivalent possibility form, gives I=◇I*. Goodsell's interpretation consequently supplies relational PA in Max_C. No instance of I is necessitated as an optional hypothesis.

### 3.3 Why quantified Frege Infinity supplies the premise

The proof in `positive-effective.md` §13.1 is correct, but its use of *current coextension* must be kept explicit.

Induction on N proves that a finite cardinality n has the same truth value on currently coextensive properties X,Y. The successor step deletes the same witness from X and Y; no identity X=Y is asserted. Under Frege Infinity, another induction proves every N-number is currently realized: if nX, X cannot be universal, by coextension invariance and the Infinity axiom; adjoining a fresh object realizes Suc n. Zero is realized by the empty property.

If Suc m=Suc n with Nm,Nn, realize this successor by X. Choose deletion witnesses a,b. If a=b, m,n share a realization. If a≠b, the recorded Swap lemma transfers n(X−b) to n(X−a), again giving a common realization. Recorded Exclusivity then gives m=n. Zero differs from every successor by evaluation at the empty property. This proves I*, hence I by reflexivity/T.

The lemmas used are in `writeups/pure-possibility-implies-axiom-of-infinity-t.md`, §1, especially Swap and Exclusivity. The proof does not import ND, Functionality, or arbitrary extensionality. It applies to any counting type σ, including t.

### 3.4 Representing oracle computation

Fix a standard acceptable effective numbering of deterministic oracle machines. Work first in ordinary first-order PA expanded by a unary predicate O and full induction in that expanded language. The usual coded finite computation formulas H_b(n,O), b∈{0,1}, can be chosen uniformly, with arithmetic operations eliminated into their relational graphs. They express that machine n on input n has a halting computation with output b.

Only two facts are used:

* PA(O) proves ∀n ¬(H_0(n,O)∧H_1(n,O)). Induct on the lesser of two purported computation lengths, using deterministic transition rules. At an oracle step the two executions inspect the same coded integer, and classical O(k)∨¬O(k) fixes the same successor configuration in both. The expanded induction in §3.1 permits this proof.
* Every externally finite actual A-oracle computation has a PA(O) proof from finitely many correct standard literals O(k̄) or ¬O(k̄). Its concrete sequence code is a standard numeral. All nonoracle checks have finite PA-verifications, and the finitely many oracle checks are precisely the supplied literals.

There is no need to represent the theory T's proof predicate in the object language. Its proof search occurs only in the external oracle program used below. There is likewise no assumption that a nonstandard model's internal apparent computations are all genuine.

## 4. The definable correct 0′ predicate passes

Let h(n) be the ordinary diagonal halting formula and define

    J(n) := □(I→h(n)).

For every standard k:

* If k halts, PA verifies its finite computation; Goodsell's interpretation gives C⊢I→h(k̄). Necessitation of this *C theorem* gives C⊢J(k̄).
* If k does not halt, the full extensional hierarchy on an infinite individual set has standard Frege arithmetic and falsifies I→h(k̄). Thus C does not prove the closed pure identity (I→h(k̄))=⊤. Max_C supplies its negation, namely ¬J(k̄).

Therefore Max_C proves exactly the correct standard 0′ literals for J. This is a statement about standard numeral instances only. It does not claim that the numerical domain of every Max model is standard, or that J behaves like external 0′ on nonstandard elements.

Given a complete actual pure extension Γ of Max_C, define d(n)=1 iff H_0(n̄,J)∈Γ. An actual 0′ computation with output 0 forces d(n)=1; one with output 1 forces H_1, and internal determinism forces d(n)=0. Thus d is binary DNR relative to 0′. In particular Γ is not computable in 0′.

The frequently omitted base-oracle issue is handled correctly in the audited note. A binary DNR^A function computes A: compile an ordinary computable index e(k) of the oracle program that ignores its input and returns the oracle's k-th bit. Then A(k)=1−d(e(k)). This uses binary range essentially; one should not silently substitute arbitrary unbounded DNR.

## 5. Independent proof of the two-search theorem

The central claim is an abstract recursion-theoretic lemma.

**Lemma.** Let A be any oracle. Suppose V_0,V_1 are disjoint A-c.e. sets containing

    K_b^A = {e : Φ_e^A(e)↓=b},  b=0,1.

Then A′ computably many-one reduces to V_0. The reduction can be chosen uniformly from fixed A-enumeration indices for V_0,V_1; its index-building function does not query A.

**Proof.** The parameterized recursion theorem for oracle-program syntax yields an ordinary total computable p(n) such that, for every oracle X, program p(n) with oracle X ignores its input and dovetails:

1. machine n with oracle X on input n;
2. the fixed X-enumerator for V_0, waiting for p(n).

It returns 0 when the first succeeds first, and 1 when the second succeeds first, with any deterministic tie rule. The oracle recursion theorem needed here is its uniform syntactic form: the compiler treats an oracle query as an instruction and never evaluates it. The standard proof by the s-m-n theorem and syntactic self-application is uniform for every oracle. Consequently p is ordinary computable even though execution of p(n) uses A.

Now specialize X=A. If n∉A′ and p(n)∈V_0, only search 2 can succeed; hence p(n)∈K_1^A⊆V_1, contradicting disjointness. Thus n∉A′⇒p(n)∉V_0.

If n∈A′ and p(n)∉V_0, only search 1 can succeed; hence p(n)∈K_0^A⊆V_0, a contradiction. Thus n∈A′⇒p(n)∈V_0.

These two implications suffice. No behavior in the case where both searches eventually succeed needs to be analyzed: the tie rule cannot undermine either contradiction argument. Therefore n∈A′ iff p(n)∈V_0. ∎

Apply the lemma with A=0′ and

    V_b={n:T⊢H_b(n̄,J)}.

The sets are A-c.e. because T is; consistency plus interpreted determinism makes them disjoint; the finite-computation argument and Max_C's correct J literals give K_b^A⊆V_b. The map n↦H_0(p(n)̄,J) is ordinary computable and reduces 0′′ to the closed pure T-theorems. The A-c.e. upper bound makes that theorem set Σ⁰₂-complete.

This proof is stronger than the separate standard-root proof and is independent of it. It remains valid for every fixed consistent 0′-c.e. addition, even if that addition excludes standard arithmetic models. It is not an appeal to Σ₁ soundness.

With A=∅ and ordinary H_b, the identical proof gives many-one complete c.e. theoremhood for every consistent c.e. theory interpreting PA in this effective way. In particular it applies to every c.e. strengthening of C plus quantified Frege Infinity.

## 6. Completion/model upper bounds and uniformity

The completion algorithm from binary DNR^A is correct. Let U be a fixed consistent A-c.e. witness theory. Given a finite consistent decision set Δ and the next sentence φ, compile a program which ignores its input and searches U+Δ proofs, returning 0 for a proof of φ and 1 for a proof of ¬φ. Choose φ when d(e)=1 and ¬φ when d(e)=0.

If one side is forced, DNR requires the matching choice. If neither side is forced, both choices preserve consistency by the deduction theorem. Thus the union is complete and consistent. All compilation is ordinary computable, and the resulting procedure is uniform in d and the fixed enumeration index for U. For A=0′, d itself supplies A as above.

Witness axioms can be added effectively in a fresh-constant schedule. They preserve consistency, and C in the expanded language is conservative under arbitrary interpretations of the fresh constants: H's Logical Equivalence instances involving constants are instances of the old variable-parameter schema. The Max axioms are still restricted to original pure terms; the construction does not impose new distinctness requirements on witness constants.

The complete witness theory D computes the representative BBK model. At each type, use the least code in each D-equality class. Representative-domain membership is D-decidable because only finitely many smaller codes need to be checked. Interpret a term under a finite assignment by substitution of the corresponding closed representatives and choosing the least equivalent term. Truth is membership of a proposition representative in D. This is exactly the sort of interpretation/truth code for which the lower bound was proved.

The relative Low Basis argument also passes. It gives a completion/model code D with D′≡0′′; the DNR lower bound makes 0′<_T D, while D′≡0′′ rules out D≡0′′. Thus 0′<_T D<_T0′′. For the c.e. positive packages the analogous construction gives low noncomputable PA degrees once strong Infinity is present.

The Medvedev comparisons use the same uniform transformations and are therefore stronger than an informal oracle-capacity comparison. Their original transformations legitimately convert a supplied completion Γ to *some* model of T without needing to preserve Γ. A later strengthening, proved in `exact-completion-model-spectra-20261022.md` §5, does preserve the supplied complete Γ uniformly and at exactly its degree: finite fresh-constant consistency is decided by asking Γ for the corresponding pure existential closure. Thus preservation is another task, but it does not require a higher oracle in this setting.

## 8. Topological and conservativity claims

The topological arguments pass with the stated syntactic/Henkin interpretation.

No consistent c.e. theory T extending C can force all Max_C axioms: racing its inequality proofs against C identity proofs would decide the c.e.-complete C identity problem. Consequently every consistent finite condition over any such T has a further consistent identity condition violating Max_C. This gives closed nowhere density, not inconsistency and not a probability claim.

Max_C is 0′-c.e. and has no 0′-computable complete extension. An isolated point in its completion space would make Max_C plus one finite condition complete and hence decidable in 0′ by proof races. This contradiction proves perfectness. Compact metrizability and zero-dimensionality then give the Cantor-space conclusion. The positive strong-Infinity packages satisfy the parallel argument with c.e. theories and ordinary PA incompleteness.

For a finite pure sentence S, the claimed equivalence also passes:

    Max_C+S consistent ⇔ C+S proves no new closed pure identities over C.

If Max_C+S is inconsistent, C+S proves a finite disjunction P of non-C identities. Each identity implies its own box by NI, so C proves P→□P. Thus C+S proves the single identity P=⊤. Equational conservativity would put P=⊤ in C, contradicting consistency of Max_C, which negates every disjunct. The empty disjunction is handled by the new identity ⊥=⊤. Combined with §5, this finite-extension conservativity test is Π⁰₂-complete.

The finite positive-package reduction was independently checked by the engine. The finite-domain sufficient condition for Functional Choice uses boxed bounds and C5, so its case-defined selector has the required identity-valued masks. This does not show that the whole Functional Choice theory is finitely axiomatizable, and the note correctly does not claim that.

## 9. New strengthening: Actuality eliminates an explicit truth-map requirement

Here is a useful refinement of the presentation boundary in `max-degree.md` §4.

**Proposition.** Let M be a C-model satisfying Actuality at its evaluation point. Suppose a code X decides equality on numbered domains and computes original term values under finite assignments, but does not explicitly contain the truth valuation. Then X computes the truth valuation once one fixed numbered Actuality witness a is hard-coded. In particular every such presentation of a Max_C+Actuality model computes binary DNR relative to 0′.

**Proof.** Actuality gives a true proposition a such that every true p satisfies a≤p. Conversely, if a≤p, then □(a→p), hence a→p by T, and therefore p because a is true. Thus for every proposition p,

    val(p)=1 ⇔ a≤p ⇔ a∨p=p.

The last test is computable from equality and parameterized term interpretation. The numerical index of a is a finite constant, so its existence suffices for a Turing reduction for this particular presentation. Evaluating closed formulas and applying §4 produces binary DNR^0′ in a Max model. ∎

This strengthens the lower bound for the recorded coalesced maximalist root, which has Actuality, and for any other Max+Actuality presentation. Uniform recovery holds from the pair (code, witness index). A uniform algorithm finding an Actuality witness from an unpointed code has not been shown and is unnecessary for the Turing-degree statement.

Two limitations are essential:

* The code must evaluate terms with the parameter a. A code evaluating only closed pure terms need not suffice.
* Max_C alone does not imply Actuality. The proved database has a separation model, `coalesced-pinned-substitutions-root`; the new proposition must not be used to remove the truth-map requirement for every Max model.

For the positive package B there is an even narrower recovery for pure sentences: recorded No Pure Contingency makes actual pure P equivalent to P=⊤, so pure equality already computes its actual pure theory. This matches `positive-effective.md` §13.2.

## 10. Remaining boundaries and attribution

No audited argument classifies arbitrary weak category/action codes, proves a degree-preserving representation theorem, determines exact degrees of all copies of a fixed structure, or identifies all positive models with the auxiliary Gallin subclass. A merely c.e. quotient equality is not decidable equality. Low relative to 0′ is not computable in 0′. A model's complete theory need not decide theoremhood of the incomplete theory it extends.

The exact comparison is therefore reliable in the following form: pure Max_C theoremhood has the second-jump degree, while obtaining one complete adequate Max model is the relative-PA completion problem above 0′; the positive strong-Infinity packages have first-jump theoremhood and the ordinary PA completion problem. These are claims about finite syntax and explicitly specified presentation tasks, not a general ordering of mathematical naturalness.
