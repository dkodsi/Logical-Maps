# Type-t uniformization: obstruction and a full-automorphism construction

22 October 2026. Continued ordinary mathematical research. This note preserves the earlier notes and database records. The arguments below are proposed research proofs, checked here but not independently reviewed or formalized; no novelty claim is made.

## 1. Target and present conclusion

Keep Classicism C, its relational grammar, and its original boxes fixed. The remaining target is a general C-model of

    □FC_(t,t) and □not Sel_t.

The full internal Gallin interpretation with E=W=omega reduces this to a ZF model in which every internal serial relation on Reals×Reals has an internal uniformizer, while Reals is not well-orderable. This equivalence, including the distinction between internal and external choices, is proved in `finite-functional-choice.md` §7. The conditional construction from Con(ZF+AD_R) remains available. Section 6 below proposes an unconditional replacement using a larger automorphism group; its central localization lemma is proved in detail and remains subject to independent review.

**The proposed Cohen reservoir from the end of that note does not supply an unconditional separator.** In its precise one-block symmetric model there is an internal real-indexed relation with no uniformizer. The obstruction uses real codes for sequences of unordered pairs and restricts the possible outputs to a ground-indexed orbit of orderings. A new real drawn from a reservoir does not repair this restriction. The proof below directly handles forcing names, stabilizers, and equality of different names.

## 2. The one-block symmetric model

Let V satisfy ZFC, let delta be a regular uncountable ground cardinal, and force with

    P = Fn(delta×omega,2,<omega).

Write c_i for its distinct Cohen reals, i<delta. Let Sym(delta) permute the column coordinate, and use the normal filter generated by Fix(S) for ground S⊆delta of size <delta. Let N be the hereditarily symmetric model.

The system gives N⊨ZF. The forcing is c.c.c. and the support filter is delta-complete, so the chain-condition preservation theorem gives N⊨DC_<delta. In particular delta=omega_2 gives DC_(omega_1), as well as ordinary DC. This is the same imported preservation theorem used in the previous note; its source is specified at the end.

Every real of V[G] belongs to N. For each bit of a name for a real, choose a maximal antichain deciding that bit. The antichains are countable by c.c.c.; their conditions together involve only countably many columns. The resulting nice name has countable support and ground check-names as children. It is hereditarily symmetric because countable sets have size <delta. Thus

    Reals^N = Reals^(V[G]).

This does not put every relation on these reals into N, and does not supply a well-order of this common real set.

## 3. The obstructing relation

Fix a ground bijection coding an omega-sequence of ordered pairs of reals by one real. For every ground injection

    a : omega×{0,1} → delta,

define two real names:

* y_a codes the raw ordered sequence (c_(a(n,0)),c_(a(n,1))) for n<omega.
* x_a codes the same sequence after sorting each pair in lexicographic order.

Sorting a pair is a fixed definable operation, including on equal reals; here distinctness is forced. Both names have the countable support ran(a), so both reals belong to N. The important asymmetry is that x_a forgets the orientation of each pair whereas y_a retains it.

Let I be the ground set of these injections, and form the name whose interpretation is

    R_0 = {(x_a,y_a):a∈I^V}.

This is an internal set of pairs of reals in N. Indeed a column permutation pi sends the pair-name indexed by a to the pair-name indexed by pi∘a. Consequently the whole name has empty support, and each child name is hereditarily symmetric. The displayed ground indexing is a specification of the name; it does not assert that the enumeration a↦(x_a,y_a) belongs to N.

One can make the name conventions exact without a choice of antichains. For a real x_a use all pairs (check k,p) for which p forces that the specified sorted code has bit k equal to 1. The forcing symmetry lemma then makes pi(x_a)=x_(pi∘a) literally true for these names. A permutation swapping only the two columns of one of a's pairs fixes x_a: the defining sorted code is forced equal before and after the swap, so its bit-forcing sets coincide. The same equivariant convention works for y_a. Alternatively, forced equality alone suffices in the contradiction below.

Put X=dom(R_0), and, inside N, extend R_0 to the serial relation

    R = R_0 ∪ {(x,0^omega):x∈Reals\X}.

ZF Separation and Replacement in N suffice for this definition. At inputs in X the allowed outputs are exactly the R_0 outputs; the default is used only outside X.

### No internal uniformizer

Suppose f∈N uniformizes R. Take a hereditarily symmetric name for f with support S⊆delta of size <delta. Choose in the ground a countably infinite collection of distinct columns outside S, organized as an injection b:omega×{0,1}→delta. Then x_b∈X, so in the actual extension

    f(x_b)=y_a and x_a=x_b

for some ground a∈I. Pairwise distinctness of all the c_i and the definition of the sorted code imply, for every n,

    {a(n,0),a(n,1)}={b(n,0),b(n,1)}.

This is an equality between ground indices: equality of the corresponding Cohen reals cannot identify different columns.

By the ordinary forcing truth lemma choose p∈G forcing that f is a function and f(x_b)=y_a. These assertions about the fixed function graph are absolute from the transitive N to V[G]. We do not apply the ordinary truth lemma to an assertion that f uniformizes all relations of the larger extension.

Since p mentions only finitely many columns, choose n such that neither b(n,0) nor b(n,1) occurs in p. Let pi transpose just these two columns. Then:

1. pi fixes the name of f, since both columns are outside S.
2. pi fixes x_b, or at least the top condition forces pi(x_b)=x_b, since its nth pair is sorted.
3. pi(p)=p, since p does not mention either column.
4. The top condition forces pi(y_a)≠y_a: a's nth ordered pair uses exactly these two distinct columns, and the transposition reverses it.

Symmetry now makes the same p force both f(x_b)=y_a and f(x_b)=pi(y_a), contradicting functionhood. Hence no uniformizer belongs to N.

This is stronger than a failure of an attempted orbit-by-orbit proof. It gives an actual internal relation without a uniformizer. It uses name automorphisms only, not purported automorphisms of the transitive N.

### Why the reservoir cannot fix this relation

At the fixed input x_b the row consists precisely of

    {y_(b flipped by h):h∈(2^omega)^V}.

The forward inclusion follows from the ground-index equality above: a and b determine a ground orientation h. The converse follows by using the ground injection obtained from b and any ground h. The map from the ground real set to this row has support ran(b), belongs to N, and is a bijection. In particular every row is individually well-orderable in N. Under ground CH these rows have size omega_1, even in the model with DC_(omega_1).

Lexicographically sorting the pairs, or using a new reservoir real to orient them, need not produce one of these ground-orientation outputs. Allowing all internal orientations would change the relation and give it an immediate uniformizer. The restricted relation is nevertheless an internal set, by the explicit invariant-name construction. Thus the obstruction cannot be dismissed because the chosen presentation uses a ground index set.

The transposition argument works for every regular uncountable delta: arbitrarily long prescribed initial segments of Dependent Choice do not make this particular symmetric construction satisfy full real uniformization. It does not say that Dependent Choice implies failure of uniformization, nor that an unconditional separator is impossible by other means.

## 4. A genuine success of the reservoir, with its exact limit

For delta=omega_2, fix a ground sequence of omega_1 distinct columns and let q=(c_(i_alpha):alpha<omega_1). This sequence belongs to N because its support has size omega_1<delta.

For any two reals x,z∈N, choose countable ground supports for their nice names. Some i_alpha lies outside their union. Its Cohen real is not in the intermediate extension generated by those supports, whereas L[x,z] is contained in that intermediate extension. Therefore c_(i_alpha)∉L[x,z].

Inside N define

    F(z,x)=c_(i_alpha), where alpha is least with c_(i_alpha)∉L[x,z].

The least ordinal exists by the preceding paragraph. Membership in L[x,z] is absolute here: both transitive models have the same ordinals and parameters, and compute the same relativized constructible hierarchy. Separation and Replacement give F∈N. Thus the reservoir really does uniformize the relation y∉L[x,z], simultaneously for all real parameters z. No simultaneous choice of supports is used in defining F; supports only prove that the defining least ordinal exists.

This explains why clearing that familiar test relation would have been insufficient. The obstruction in §3 is an arbitrary internal relation built from an invariant ground orbit, rather than a requirement merely to find a new real outside a constructible hull.

## 5. Countable condition supports alone do not repair the Cohen construction

A different attempted repair changes the forcing to the countable-support product of delta=omega_2 Cohen forcings, retaining the column-permutation group and the filter of supports of ground size <delta. Its symmetric model still satisfies ZF. No Dependent Choice preservation claim is needed for this paragraph.

The sorted-pair argument above no longer works: a condition may mention every pair. In fact one can strengthen a condition to decide all the pair comparisons simultaneously; thus the sorting orientation of any fixed ground-indexed sequence is a ground real. The earlier restricted row then contains the sorted output.

Nevertheless a different obstruction applies. A countable full-support product of Cohen forcing makes the ground real set countable. Here is an explicit coding proof. Write its generic matrix as (c_n:n<omega). For each initial integer k define a real z_k by a walk through the rows. Start at position j_0=k in row 0. In row n, count the consecutive 1s beginning at j_n up to the next 0; call that length j_(n+1), and let z_k(n) be the bit immediately following that 0. Each row has arbitrarily late zeros. Given any ground r∈2^omega and any condition represented by finite strings (s_n:n<omega), choose k≥length(s_0). Successively choose j_(n+1)≥length(s_(n+1)) and extend row n from j_n by 1^(j_(n+1)), then 0, then r(n). These are finite extensions at every coordinate and together form a valid full-support condition. They force z_k=r. Hence the z_k enumerate a set containing every ground real; replacing nonground values by a fixed ground default gives a surjection onto the ground real set.

Consequently any allowed ground support S, of ground size at most omega_1, becomes countable in a subextension using only a fixed countable set T of columns. The generic column map restricted to S∪T has support S∪T and belongs to the symmetric model. There is therefore a real x, with a name supported by S∪T, coding a sequence that contains every c_i with i∈S∪T.

Let A={c_i:i<delta}. As before A is not well-orderable in the symmetric model: a putative well-order with support S would choose a least member of A\{c_i:i∈S}; a fresh-column transposition and compatible conditions contradict that choice. In particular no sequence enumerates A. Thus the internal relation

    R(x,y) iff y∈A and y is absent from the real sequence coded by x

is serial on all reals. If f uniformized it and had support S, use the preceding x coding all columns in S∪T. Then f(x)=c_i for some i outside S∪T. Take a condition forcing this evaluation and transpose i with a new column outside S∪T and the condition's countable support. The transposition fixes f and x, and the two conditions are compatible, while their forced outputs are distinct. This is a contradiction.

Thus merely replacing finite conditions by countably supported Cohen conditions also fails, for a different reason: the product's collapse lets one real capture all columns in a candidate function's support, together with the columns used to obtain that capture.

## 6. A different symmetry group: a proposed unconditional separator

The successful direction suggested by the preceding failures is to change the group, not just the size of supports. The argument in this section is a new research proof. Its extension-of-embeddings step is spelled out because invariance under column permutations alone is insufficient.

Work over V=L and put kappa=omega_2. Let B be the complete Boolean algebra of Add(omega,kappa). For S⊆kappa let B_S be its complete coordinate subalgebra. Use the **entire group Aut(B)**, and the normal filter generated by the pointwise stabilizers

    H_S={pi∈Aut(B):pi(b)=b for every b∈B_S},   |S|<kappa.

These stabilize Boolean-algebra elements pointwise. They are not just groups of column permutations. Let N_* be the resulting hereditarily symmetric model.

### 6.1 Verify the system and the failure of a real well-order

Every element b∈B lies in B_T for some countable ground T: take a maximal antichain of finite Cohen conditions below b, and collect its columns. The antichain is countable. More generally, a complete subalgebra of B with a dense set of size lambda is contained in B_T for some |T|≤lambda+aleph_0, by applying this argument to a dense set and then using completeness of B_T.

In particular pi[B_S] is contained in some B_T with |T|<kappa, for every pi∈Aut(B). Thus H_T⊆pi H_S pi^(-1). This proves normality of the filter. Intersections of fewer than kappa many generating subgroups contain the subgroup for the union of their supports, so the filter is kappa-complete. It is proper: a tail-coordinate bit flip is a nonidentity element of every H_S. Each Boolean condition has a countable support, so conditions are tenacious for this filter. The symmetric-extension theorem and the chain-condition preservation theorem yield

    N_* ⊨ ZF + DC_(omega_1).

Every real of V[G] lies in N_*: its bit truth values together have countable coordinate support. Also V[G_S]⊆N_* for every ground |S|<kappa, since all B_S-names are hereditarily fixed by H_S.

The fixed Boolean algebra of H_S is exactly B_S. To see the nontrivial inclusion, take b fixed by H_S and a countable coordinate support T for b. A column permutation fixing S can move T\S to a fresh countable set. Then b belongs both to B_T and to the moved coordinate algebra. Coordinate subalgebras of a product Cohen algebra intersect in the subalgebra on their common coordinates, giving b∈B_S. The intersection assertion can also be checked directly: if a regular-open truth value depended nontrivially on coordinates available only on one side, two finite conditions agreeing on the common coordinates could force opposite values; independence of the other side would contradict its membership in both algebras.

It follows that every set of ordinals belonging to N_* lies in some V[G_S], |S|<kappa. Indeed, take a supported name and replace it, below a sufficiently large ordinal bound, by its canonical Boolean membership name. Each coefficient ||check alpha∈dot Z|| is fixed by H_S, hence belongs to B_S.

If N_* had a well-order of its reals, it would have an ordinal-indexed enumeration of them. Its bit matrix is a set of ordinals, hence belongs to one V[G_S]. Decoding the matrix there would place every real of N_* in V[G_S]. But N_* and V[G] have the same reals, and any column outside S supplies a real not in V[G_S]. Therefore

    N_* ⊨ not WO(Reals).

### 6.2 The Boolean-algebra facts needed to move a witness

The following elementary forcing facts are used in their relative forms.

1. A complete subalgebra of a Boolean algebra with a countable dense set again has a countable dense set: project the dense set onto the subalgebra. A quotient of such an algebra by a complete subalgebra also has a countable dense set in the intermediate extension. For the quotient statement, express each positive condition as a countable join of dense-set members below it; genericity ensures that one member survives the quotient.
2. Every complete Boolean algebra with a countable dense set is a sum of at most countably many atoms and, possibly, one atomless Cohen part. For the atomless part, the Boolean algebra generated by a countable dense set is countable and atomless, and its completion is the Cohen algebra. Consequently every such complete algebra embeds completely into one Cohen algebra, by assigning its atoms and its possible atomless part to a finite or countable Boolean partition represented by clopen sets. In the infinite case their union need only be dense: their regular-open join is 1. Map each atomic component to its assigned piece and use a Cohen isomorphism on the possible atomless component.
3. If Q has a countable dense set, then Q followed by Add(omega,kappa) has completion isomorphic to B. On each atomic component of Q the first forcing is trivial; on its atomless component it is Cohen forcing. A Cohen factor is absorbed by the kappa remaining Cohen coordinates. A countable sum of copies of B is again B, as witnessed by such a Boolean partition using one coordinate; below each of its basic clopen pieces the completion is again the kappa-coordinate Cohen algebra.

All three statements hold inside the relevant intermediate ZFC models. Quotient factorizations and Boolean names for the stated embeddings or isomorphisms therefore give their relative versions by the forcing theorem. This includes mixed atomic/atomless quotients; no assumption that every quotient is atomless is being made.

The countability is relative to the already fixed base B_S. No claim is made that every complete subalgebra of a Cohen algebra of density omega_1, or every quotient by one, is itself Cohen. Here the relevant intermediate algebras all lie between B_S and B_(S∪T) with T countable. This is what permits (1)–(3) to apply.

Here is the precise extension step. Suppose T is countable, A=B_(S∪T), and C is a complete subalgebra satisfying B_S⊆C⊆A. Choose i outside S∪T and let D be the complete algebra generated by C and the independent i-th Cohen coordinate. Then A/C has a countable dense set in the C-extension: first factor out B_S, after which only countably many Cohen coordinates remain, and apply (1). By (2), this quotient embeds into the i-th Cohen algebra. Lifting the quotient embedding gives a complete embedding

    j:A→D,       j restricted to C = identity.

This j extends to an automorphism pi of the entire B. For B/A the remaining forcing is Add(omega,kappa). For B/j[A], first factor through B_(S∪T∪{i}). Its quotient by j[A] has a countable dense set, because j[A] contains B_S and the remaining coordinates at this stage are countable. The unused kappa coordinates then absorb this quotient by (3). Thus B has factorizations over A and over j[A] with isomorphic Cohen remainder; the isomorphism j on the first factors, together with a Boolean name for an isomorphism of their remainders, gives an automorphism of B extending j. In particular pi fixes B_S and C pointwise.

More explicitly, put P=Add(omega,kappa). Choose the factorization isomorphisms from B onto the Boolean completions of A*check P and j[A]*check P so that each is the canonical inclusion on its first factor. The isomorphism j transports A-names recursively to j[A]-names and fixes ground check-names. Hence it induces an isomorphism between these two completed iterations. Compose the first factorization, this transported isomorphism, and the inverse second factorization. The resulting automorphism of B restricts to j on A. The quotient equivalences used to choose the factorizations are Boolean names chosen in the ground by the forcing maximum principle; no automorphism of an actual transitive extension is being asserted.

### 6.3 Localization of one real witness, fixing the input exactly

Let dot R be a name fixed by H_S. In the actual extension suppose x and y are reals with R(x,y). Choose canonical real names dot x,dot y, and let

    b=||R(dot x,dot y)|| ∈ G.

Enlarge a countable T so that the two real names and b are all in A=B_(S∪T). Let C be the complete subalgebra generated by B_S and the bit values of dot x. Then

    V[G∩C]=V[G_S][x].

This is the usual intermediate-model factorization for a real name. Fix any i outside S∪T and construct j:A→D and its automorphism extension as in §6.2. The projection of j(b) to C equals the projection of b to C, which belongs to G∩C. Thus, in V[G∩C], j(b) is a nonzero regular-open condition of the i-th Cohen forcing.

Choose a finite binary string s below this nonzero quotient condition. A finite bit flip h on coordinate i can send the actual c_i into the basic open set [s]. All finite binary strings and finite bit flips already belong to the ground. Since h is its own inverse, c_i belongs to h([s]), which is below h(j(b)) in the quotient. Replace the extension of j by h composed with it. Then

    pi(b)∈G,       pi restricted to C = identity.

Here pi fixes the input name exactly, since it fixes every Boolean bit value of dot x. It also fixes dot R, since pi∈H_S. The symmetry lemma consequently gives R(x,(pi dot y)^G). The transformed output name has all its coefficients in D, so

    (pi dot y)^G ∈ V[G∩D] = V[G_S][x,c_i].

We have proved: a real witness to an H_S-invariant relation can be replaced by a witness in V[G_S][x,c_i], whenever i is outside a countable support for the input, the original witness, and the membership truth value. The point of using the full automorphism group is precisely the extension step in §6.2. The proof does not choose a representative of an input-name orbit, and does not identify different names merely because their values happen to coincide.

### 6.4 Obtain one internal uniformizing function

Take any serial R⊆Reals×Reals in N_* and a supported name as above. Put M=V[G_S]. Since V=L, choose a set of ordinals a∈M coding the restricted generic filter so that M=L[a]. Fix in the ground a sequence U=(i_alpha:alpha<omega_1) of distinct columns outside S. The sequence q=(c_(i_alpha):alpha<omega_1) belongs to N_*, with support U.

For each real x, take one witness y to R(x,y) for the purpose of the argument. The names of x,y and the membership Boolean value use only countably many extra columns. Some i_alpha avoids them. Section 6.3 then supplies a witness in

    M[x,c_(i_alpha)] = L[a,x,q(alpha)].

Inside N_* choose the least alpha for which this inner model has an R(x,-) witness, then choose its least such real under its canonical constructible well-order. The relative constructible universe is the same in N_* and V[G]: it has set-of-ordinals parameters and both transitive models have the same ordinals. Its real set and its canonical well-order belong to N_*. Thus this least-choice definition is an ordinary definition in N_*, and Separation and Replacement produce a single function f∈N_* uniformizing R.

There was no simultaneous preliminary selection of witnesses, supports, embeddings, or bit flips. Those were used only to prove that the definable least-alpha search succeeds for each input. The actual uniformizer is defined from the fixed parameters R,a,q. In particular equal input reals receive equal outputs irrespective of which names were used in the existence proof. The parameters a,q are fixed once for this R; no single operation assigning such parameters or uniformizers to all R is asserted. The needed quantifier order is forall R exists f.

The proposed conclusion is therefore an ordinary-ZFC symmetric construction of

    ZF + DC_(omega_1) + Unif(Reals) + not WO(Reals).

As in the earlier note, forcing is used through its formal relation and finite-proof absoluteness, rather than by assuming a transitive set model of ZFC. Beginning with L costs no additional consistency strength over ZFC. Interpreting the full internal Gallin hierarchy with E=W=omega yields □FC_(t,t) and □not Sel_t at every world. First-order Henkin extraction as in the earlier note gives a general C-model in the ground metatheory. This is the proposed unconditional type-t separation; the proof's new component is the full-group localization in §§6.2–6.4, and it has not been independently checked.

### 6.5 Checks distinguishing this construction from the failed one

The sorted-pair relation from §3 is not invariant under the full group in the way required by this argument. There is an explicit additional Boolean automorphism: use the bits of a fresh Cohen column to decide independently whether to swap the two columns in each pair of a fixed countable sequence. This is an involutive homeomorphism of the relevant countable Cantor cube, hence an automorphism of its Cohen completion and of B. It fixes the sorted input code, but changes the raw output by a fresh, nonground orientation. That transformed output is absent from the old ground-orientation row. The invariant-name argument for §3 therefore cannot be transferred to §6.

Another concrete check is an input x=c_j XOR c_k. Fixing x does not require fixing c_j and c_k separately: a full Boolean automorphism can replace that decomposition by c_i and x XOR c_i while preserving x. Column permutations alone cannot implement such a replacement. Section 6.2 is the general, quotient-algebra version of this distinction, including inputs without a simple displayed decomposition.

The size of the support allowance also matters. Even keeping kappa=omega_2 and the full automorphism group, restricting the filter generators to countable S makes the serial relation y∉L[x] lack an internal uniformizer. For a candidate f supported by H_S, S countable, code the restricted generic filter by a real r so that V[G_S]=L[r]. The value f(r) has Boolean bit values fixed by H_S, hence lies in V[G_S]=L[r], contradicting the relation. Seriality follows because each real uses countably many columns and a new column exists outside them. The same argument applies at kappa=omega_1 with countable supports. Thus enlarging the group alone does not prove the proposed theorem: allowing an omega_1-sized reservoir, which one input real cannot capture, is essential to the argument at kappa=omega_2. Indeed q is not in L[r] for any real r: a countable coordinate support for r omits some reservoir column, whereas q∈L[r] would put every entry of q in L[r].

The audit has specifically kept separate: a Boolean condition versus a finite Cohen condition; a complete embedding versus its extension to an automorphism; relative countable density versus density omega_1; atomic versus atomless quotient pieces; positive quotient membership versus actual membership in G; and existence proofs using names versus the final set-defined uniformizer. The last passage uses the least ordinal and an actual constructible well-order, so it is independent of names and contains no additional choice over real inputs. No gap in these steps has been identified in the present checks; this is not an independent verification.
