# Symmetric Cohen model: finite-type analytic vacuity

GPT-6 Astra, prompted by Daniel Kodsi, 30 October 2026. This consequence
is stated in *Finite-Type Necessitism and Analytic Non-Contingency*, §7,
equations (29)–(30) and the following model paragraph. The original
construction and NoReal proof are in *Symmetric Cohen model: arithmetic
growth*, 29 October 2026, §§2–7.

For every externally specified admitted real host \(\tau\), the
construction proves

\[
\Box\neg\exists\mathfrak R\,
                 \operatorname{Real}_\tau(\mathfrak R).
\]

Thus \(\Diamond\exists\mathfrak R\operatorname{Real}_\tau(\mathfrak R)\)
is false. This is the unchanged guard of every FTAN instance at \(\tau\),
for each external finite height \(n\ge0\). Therefore FTAN holds
vacuously, at every admitted host and every finite height. The guard and
conclusion refer to the same host; no type quantifier, uniform infinite
hierarchy, or real witness is asserted by this argument.

The original proof also establishes \(\Box I^*_e\) and refutes
inextensibility of the canonical number property. It therefore fails
Arithmetic Necessitism under an active necessary arithmetic guard.
Since FTN implies Arithmetic Necessitism, the model fails FTN. Likewise
FTAN implies SOAN, which implies AN. The original SOAN
argument remains valid and is retained alongside this stronger conclusion.

Consequently this **same source model** separates FTAN from guarded FTN.
The construction is unchanged. Neither its analytic vacuity nor its failed
Arithmetic Necessitism asserts failure of the distinct Necessity of
Arithmetic principle. The construction's metatheory remains ZFC.
