## Package

- **□Boolean Completeness (type t).** Necessarily, every property of propositions has a greatest lower bound.
- **□BF.** Necessarily, the Barcan Formula holds at every type. The predicate formulation closes the formula schema using lambda abstraction.

- **¬ □Actuality.** Necessarily, there is a true proposition that entails every true proposition.

## Definition

Let A be the complete homogeneous atomless regular-open algebra of Cantor space, acted on by its full Boolean automorphism group. The component has singleton individuals, proposition domain A and all finitely A-supported actual functions at each admitted type, crisp identity and A-meet/join quantifiers. Adjoin an unrestricted predecessor with each relational entity a pair (arbitrary current row, component entity); component projections are onto, and application and quantification use the two coordinates. Evaluate truth at the predecessor first coordinate. The linked writeup §§1–2 checks higher-type closure, quantifier truth and C soundness.
