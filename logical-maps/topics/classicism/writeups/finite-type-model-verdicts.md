# Finite-Type Necessitism in coalesced and stitched models

GPT-6 Astra, prompted by Daniel Kodsi, 29 October 2026.
These arguments concern the guarded Finite-Type Necessitism (FTN) schema.

Write \(N_\sigma\) for the canonical Frege number carrier and
\[
 H_{\sigma,0}=N_\sigma,\qquad
 H_{\sigma,n+1}=\lambda Q\,
   (\operatorname{Rigid}(Q)\land Q\le H_{\sigma,n}).
\]
Each FTN instance has antecedent \(\Box I^*_\sigma\) and requires the
next canonical carrier to be a full rigid represented power. The source
types and finite indices are external schema parameters. Necessary local
fullness at one stage is distinct from inextensibility of the next power
carrier.

## Complete-component coalesced roots

Fix any counting source \(\sigma\). In the full one-world model with one
individual, every admitted type has a finite domain. The sufficiently large
Frege cardinalities at \(\sigma\) coincide at the empty cardinality
profile, so successor is not injective on the number carrier.
Consequently \(\neg I^*_\sigma\) is consistent with C.

For a coalesced root whose components are complete for C, some accessible
component root satisfies this pure sentence. Its possibility at the new
root refutes \(\Box I^*_\sigma\). This works separately at every source,
so every guarded FTN instance holds vacuously. It asserts neither an
activated Peano carrier nor a full hierarchy at the root. The condition is
`complete-components`; it does not require a free current root profile or
restriction to distinguished root arrows, just as the group's existing
arithmetic-necessitism argument does not.

In particular, the existing failures of analytical truth principles in
these very models are compatible with FTN. The false-guard argument must
not be used to infer an unguarded analytical or hierarchy assertion.

## Stitched forcing that adds a real

Use exactly the group's Barton–Goodsell construction. Its root has ground
current profiles paired with terminal profiles definable from ground
parameters; its terminal object is the full extensional hierarchy of the
generic extension. This is not a replacement by externally full root
domains. A root relation \((E,D)\) is rigid exactly when
\(D=\pi[E]\), as in the group's existing Rigid Comprehension argument.

The canonical \(e\)-counting number carriers at root and endpoint
identify with the ground's natural numbers; forcing preserves those
numbers, and projection carries each numeral to the corresponding one.
The admitted predicate of all these numerical values excludes any
non-numerical root cardinality from the least inductive field. Thus
\(\Box I^*_e\) holds and the number carriers are rigid and bijectively
transported. This is internal to the ground construction: when the ground
model is not externally standard, no assertion that its natural-number
domain is the external \(\omega\) is needed.

For a ground subset \(S\) of that number carrier, the paired predicate
with current extension \(S\) and terminal extension its numeral image
is admitted and rigid. Conversely, a current rigid predicate supported on
\(N_e\) has exactly such a terminal image of its ground current extension.
These are precisely the current members of \(H_{e,1}\).

At the terminal object all relations are rigid and its domain is full.
If the forcing adds a real \(c\subseteq\omega\), its characteristic
predicate belongs to the terminal \(H_{e,1}\), but is not the transport
of any current member. To detect that missing member, take a root test
predicate whose current extension is all current \(H_{e,1}\)-members
and whose terminal extension is exactly the image of that set. The latter
is definable from the ground parameter \(\mathcal P(\omega)^V\) and
the numeral maps. Both profiles therefore meet the stitching admission
rules. No ground definition of \(c\) is required.

This test necessarily holds of each current power member but misses the
new terminal member. It refutes inextensibility, hence rigidity, of
\(H_{e,1}\). The active-guard FTN instance requiring that carrier to be
a full rigid power therefore fails. Necessary local fullness on \(N_e\)
may still hold: the new terminal predicates have representatives there.

The proof uses only `adds-a-real` beyond the group's construction
hypotheses. It therefore applies to the existing Cohen and CH-reversing
members, including their constructible-ground variants. The proof uses the
ground/extension stitching construction; a full Boolean-valued hierarchy
requires a separate canonical-carrier argument.
